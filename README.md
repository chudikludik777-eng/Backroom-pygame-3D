# 📦 Backroom Pygame 3D

Это атмосферный 3D хоррор в сеттинге "Закулисья", созданный на движке Pygame. Игра обычная просто нужно найти выход.

## 🚀 Как запустить игру

Чтобы поиграть или поработать с кодом, выполни эти шаги:

### 1. Клонирование репозитория
Открой терминал и введи:
```bash
git clone https://github.com/chudikludik777-eng/Backroom-pygame-3D
cd Backroom-pygame-3D


2. Дальше нужно поставить окружение тоесть .venv

python -m venv .venv
# Активация для Windows:
.venv\Scripts\activate

3. Скачать эти библиотоки в том же терминале

pip install pygame numpy

4. Чтобы запустить игру нужно ввести

python backrooms.py

🎮 Управление
WASD — Передвижение
Мышь — Обзор
ESC — Выход
